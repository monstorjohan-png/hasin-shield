# حصن 🛡️ — درع العفة والتركيز

تطبيق ويب تقدمي (PWA) بالعربية، يعمل دون إنترنت، وقابل للتثبيت كتطبيق على أندرويد من المتصفح.

## ما يفعله
- ⏰ جدولة منع التطبيقات/المواقع (تنبيه + سجل عند دخول وقت الحجب)
- 🔒 وضع التركيز بملء الشاشة مع كلمة سر اختيارية
- 🧭 فاحص روابط ضد قوائم إباحية + كلمات عربية/إنجليزية + كلماتك الخاصة
- 🌱 عداد أيام نظيفة + سجل مساءلة قابل للنسخ لشخص ثقة
- 🛡️ دليل تفعيل الحماية الحقيقية (DNS العائلة + Digital Wellbeing)

## ما لا يستطيعه أي موقع (بصدق)
المتصفح لا يستطيع حجب تطبيقات أخرى — أندرويد يمنع ذلك أمنيا.
الحجب الحقيقي = DNS العائلة (`family.adguard-dns.com`) + مؤقتات التطبيقات.
هذا التطبيق هو مركز القيادة والالتزام، وتلك الإعدادات هي الحجب الفعلي.

## النشر الدائم (رابط https + تثبيت كتطبيق)
الملفات ثابتة — لا تحتاج سيرفر خاص:
1. افتح https://app.netlify.com/drop (أو Cloudflare Pages / Vercel)
2. اسحب مجلد `hasin-shield` كاملا
3. تحصل على رابط دائم `https://…` — شاركه، ومن Chrome: ⋮ ← تثبيت التطبيق

## التشغيل محليا
```powershell
cd hasin-shield
npx -y serve .
```
ثم افتح `http://localhost:3000`

## الخصوصية
كل البيانات في `localStorage` على جهازك فقط. لا سيرفر، لا تتبع، لا حسابات.
